# Weather Dashboard
A responsive front-end web application that provides real-time weather information and a 5-day forecast for any city using the OpenWeatherMap API.
## Features
- Real-time digital clock display
- Current weather data (Temperature, Humidity, Description)
- 5-Day forecast breakdown
- Interactive UI built with AngularJS and jQuery
## How to Run
1. Clone or download this repository.
2. Open index.html 2. n any modern web browser.
3. Add your free API key from [OpenWeatherMap](https://openweathermap.org/) into index.html where indicated.
